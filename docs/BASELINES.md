# Baselines

Scores of CSyk and of plain text search on the same questions, recorded with
`npm run eval -- --adapter <csyk|b0> --corpus <name>`, one repository per process. Recorded
2026-10-29 on an Apple-silicon laptop (16 GB), with the language servers already running except
where noted.

The two ways to answer:

- **Text search** (`b0` in commands): what an agent does with only built-in tools. It searches
  with ripgrep, then reads the first matching file whole; for uses and callers, the matching lines
  are its answer. It cannot find what a function calls, so for callers and calls it answers only
  the callers half.
- **CSyk**: `find` for exact names and parts of names, `refs` for uses, `calls` for callers and
  calls, `grep` for messages, `impact` for edit impact.

The six kinds of question, with the letter each has in commands and file names:

- **Exact name** (A): find every declaration of a name, as the compiler's outline spans it.
- **Part of a name** (B): a few words that match exactly one name in the repository.
- **Uses** (C): every mention the compiler resolves to the declaration.
- **Callers and calls** (D): from the compiler's call hierarchy, leaving out callers that only call
  `super.m()`.
- **Message** (E): a sentence written once in the repository; the answer should name the function
  it is in, among the first five.
- **Edit impact** (G): one or two lines changed inside one or two functions; the answer should name
  those functions and their callers two levels up.

Questions are generated by `eval/generate.ts` from each language's own compiler (`tsc --lsp`,
pyright, gopls, the Dart analysis server), with a fixed random seed, 30 of each kind unless a small
repository has fewer, leaving out tests, generated code, local variables and names that are only
imported.

"Found" is the share of the right answers that an answer contains; "correct" is the share of an
answer that is right.

## What the numbers say

- **Definitions.** Text search cannot rank, so an exact-name search often opens an importing file first,
  and it cannot match a partial name at all. CSyk's first answer is the
  declaration 98.6% of the time on exact names and 99.5% on partial ones.
- **Uses.** Text search finds every use, but a third of what it returns is noise: comments,
  strings, import paths and same-named symbols elsewhere. Resolving each mention through the
  language server removes
  nearly all of it.
- **Callers.** Searching for `name(` finds most callers but also declarations and same-named functions, and nothing for
  callees. CSyk follows calls, constructions, decorators, JSX and callbacks, and calls through
  interfaces and base classes in the workspace.
- **Tokens.** Across exact names, parts of names, uses and messages, CSyk returns about a
  seventieth of what text search and a whole-file read cost (240 tokens against 16,899).
- **Time.** Warm answers take single-digit milliseconds for names and tens of milliseconds for
  references and callers. Searches over very common names (Django's `Model.save`, Prometheus's
  hub methods) are bounded at five or six seconds and say when they are partial.

## Where the gaps are

- **Dart edit impact (provider 70.9%, flame 71.4%).** The Dart server's call hierarchy counts implicit
  `super(...)` constructor calls (Dart 3 primary constructors) and calls through framework bases
  such as Flutter's `State` or `Diagnosticable`, which reach every override. CSyk follows
  supertypes declared in the workspace only: following framework hierarchies takes the server
  tens of seconds and returns mostly framework calls.
- **TypeScript.** `tsc`'s call hierarchy counts calls to any implementation of an interface method
  as calls to each; CSyk adds the compiler's own search for methods with supertypes, to match.
- **Python "correct" on callers and edit impact** (Django edit impact 47%) is lower than it really
  is: pyright's call hierarchy misses calls
  through module aliases (`conversation_flows.set_conversation_topic(...)`) and inferred receivers
  (`user.get_organization_role(...)`) that CSyk finds and that are real calls.
- **Go.** A function declared twice under opposite build tags resolves to the copy `gopls` builds
  by default (pocketbase, part of a name). Prometheus's most used methods hit the search time limit
  on uses, callers and edit impact.
- **Renamed imports** (`import { a as b }`, default imports under another name) are not followed.

**Uses against the servers' own search** (measured on an earlier question set): CSyk's uses were
compared with `textDocument/references`, a different algorithm. They agreed on every case for gopls
and Dart and on 29 of 30 for pyright (a name listed as a string in `__all__`); on excalidraw CSyk
added only the import and export specifiers `tsc` leaves out, and missed one default import under
another name.
