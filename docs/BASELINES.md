# Baselines

Tool-level scores of CSyk and of the two baselines from PLAN.md §7.4, recorded with
`npm run eval -- --adapter <csyk|b0|b1> --corpus <name>`, one corpus per process. Recorded
2026-10-29 on an Apple-silicon laptop (16 GB), language servers warm except where noted.

- **B0:** built-in tools only: ripgrep, then a whole-file read of the first match; for references
  and callers the grep lines are the answer. It cannot find what a function calls, so it answers
  only the callers half of D.
- **B1:** CodeSift over MCP, as its own rules direct (`search_symbols` with source,
  `find_references`, `trace_call_chain`, `search_text`). It has no `impact` for an edit, so it
  answers no G.
- **CSyk:** `find` for A and B, `refs` for C, `calls` for D, `grep` for E, `impact` for G.

Cases are generated by `eval/generate.ts` from each language's own server (`tsc --lsp`, pyright,
gopls, the Dart analysis server), seed 1, 30 per category unless a small repository has fewer,
leaving out tests, generated code, function locals and names that are only imported. A expects
every top-level or member declaration of a name, as the server's outline spans it. A B query is
answered by exactly one name in the repository. C is every mention the server resolves to the
declaration. D and G come from the server's call hierarchy (callers that only call `super.m()`
left out); G edits one or two lines inside one or two functions and expects those functions and
their callers two levels up. E is a sentence written once in the repository.

## What the numbers say

- **Definitions.** Grep cannot rank, so an exact-name search often opens an importing file first,
  and it cannot match a partial name at all. CodeSift ranks better but misses module constants,
  class attributes and, on Dart, every symbol (it indexes none). CSyk's first answer is the
  declaration 98.6% of the time on exact names and 99.5% on partial ones.
- **References.** Grep finds every reference, but a third of what it returns is noise: comments,
  strings, import paths and same-named symbols elsewhere. CodeSift's `find_references` is text
  based and scores about the same. Resolving each mention through the language server removes
  nearly all of it.
- **Callers.** CodeSift's call chain finds a third of the callers the servers report. Grep for
  `name(` finds most callers but also declarations and same-named functions, and nothing for
  callees. CSyk follows calls, constructions, decorators, JSX and callbacks, and calls through
  interfaces and base classes in the workspace.
- **Tokens.** Across A, B, C and E, CSyk returns about a seventieth of what grep and a whole-file
  read cost (240 tokens against 16,899) and a fifth of CodeSift's (1,322). Per category it is a
  seventh of CodeSift's on A, a fourteenth on B and a third on C; on D and E CodeSift's bare lines
  are shorter, since CSyk also names each caller's or match's enclosing symbol.
- **Time.** Warm answers take single-digit milliseconds for names and tens of milliseconds for
  references and callers. Searches over very common names (Django's `Model.save`, Prometheus's
  hub methods) are bounded at five or six seconds and say when they are partial.

## Where the gaps are

- **Dart G (provider 70.9%, flame 71.4%).** The Dart server's call hierarchy counts implicit
  `super(...)` constructor calls (Dart 3 primary constructors) and calls through framework bases
  such as Flutter's `State` or `Diagnosticable`, which reach every override. CSyk follows
  supertypes declared in the workspace only: following framework hierarchies takes the server
  tens of seconds and returns mostly framework calls.
- **TypeScript.** `tsc`'s call hierarchy counts calls to any implementation of an interface method
  as calls to each; CSyk adds the compiler's own search for methods with supertypes, to match.
- **Python precision on D and G** (Django G 47%) understates: pyright's call hierarchy misses calls
  through module aliases (`conversation_flows.set_conversation_topic(...)`) and inferred receivers
  (`user.get_organization_role(...)`) that CSyk finds and that are real calls.
- **Go.** A function declared twice under opposite build tags resolves to the copy `gopls` builds
  by default (pocketbase B). Prometheus's hub methods hit the search deadline on C, D and G.
- **Renamed imports** (`import { a as b }`, default imports under another name) are not followed.

**C against the servers' own search** (measured on the P4 case set): CSyk's references were
compared with `textDocument/references`, a different algorithm. They agreed on every case for gopls
and Dart and on 29 of 30 for pyright (a name listed as a string in `__all__`); on excalidraw CSyk
added only the import and export specifiers `tsc` leaves out, and missed one default import under
another name.
